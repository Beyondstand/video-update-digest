# 视频更新速递 · KeyDock（Edge 扩展）

版本 1.4.0。监控 B 站 / 抖音作者，用用户自己的 OpenAI 兼容模型生成视频总结、截图长图，并经 HTTPS→SMTP 中继发送邮件。本版本没有内置体验 Key，模型费用由用户自己的 API 服务商结算。可选「生成讲解页」（弹窗勾选）：每封邮件额外附带 lecture.html——按 Manim 图文讲解风格排版的分步教学网页（章节导航、先直觉后公式的讲解文案、视频截图插图），零依赖单文件，浏览器打开即可离线阅读。

## 安装或更新

在 Edge 打开 edge://extensions/，启用开发人员模式，加载包含 manifest.json 的目录。已有安装点击“重新加载”。邮箱、监控设置和发送记录保留；升级会清理旧的共享体验 Key。复制 Key 功能使用 clipboardWrite 权限。

## 配置 API（简单说明）

1. 打开插件，点击“管理 API · KeyDock”，然后“添加平台”。
2. 网站网址填写服务商控制台网址；模型 API 地址填写其 OpenAI 兼容 base URL，例如 https://api.example.com/v1。两者用途不同，不要把 Key 填进网址。
3. 在 API Key 栏输入自己的完整 Key。点击“读取可选模型”，然后在“模型 ID”输入框的列表中选择。服务商未提供 /models 接口时，可以手动填写其文档给出的准确模型 ID。
4. 保存平台，再点击卡片上的“用于总结”。弹窗也可以切换已就绪的平台。
5. 回到弹窗填写作者、收发邮箱、SMTP 授权码、中继地址和中继密钥，保存后检查更新。

读取模型列表仅在点击按钮时请求模型 API 的 /models，使用填写或已保存的 Key。列表最多显示 300 个模型 ID；失败时可手动填写。没有预设服务商或模型，请使用自己的服务商资料配置。

## Key 与配置保管

个人 Key 默认仅保存在 chrome.storage.session，浏览器重启、扩展停用或重新加载后清除。可在 KeyDock 管理页启用「加密保存」：以保管密码（PBKDF2-SHA-256，30 万次迭代派生 AES-256-GCM 密钥）将全部个人 Key 加密后存入本机；浏览器重启后在管理页输入一次保管密码即可解锁恢复，免重输 Key。会话期间录入或自动读取的新 Key 会同步加密进本机副本；「锁定」只清除会话明文，不影响加密副本；「停用加密保存」删除本机副本（需验证保管密码）。保管密码不保存在任何位置，忘记后无法解密，只能停用后重新录入 Key。平台、模型信息和当前选择保存在本机。已核实只读 JSON 接口的平台可自动读取；自动读取在锁定期间也能补充会话 Key，解锁时会一并加密保存。

API 管理页不导入、展示或向模型发送邮箱地址、SMTP 授权码、中继密钥。邮箱和中继配置保存在 chrome.storage.local。Key 失效、清空或删除后停止新的模型调用，不会自动使用其他 Key。已生成的报告可以重试发信，无需重复调用模型。修改 API 地址或模型 ID 会中止正在进行的模型任务，等待重试。

Key 默认遮罩显示，可短时显示或主动复制。复制会将 Key 写入系统剪贴板。本机配置与会话存储不能防御已受控制的设备或浏览器。

## 浏览历史与每日报告

本版本整合浏览日志功能，与视频任务共用 KeyDock 当前选中的 API 和邮箱中继。插件弹窗新增“浏览日报 · 历史记录总结”入口，以及“将浏览日报发送到邮箱”复选框。

1. 打开“浏览日报”，进入“日报设置”。采集新页面正文、定时生成、日报邮件三个开关默认关闭。
2. 可开启“启用网页内容采集”，之后访问或刷新 HTTP(S) 网页时采集标题、URL 与最多 4000 字摘录。支持 SPA 地址变化。排除站点命中时不采集，也不进入模型总结。
3. 在“共用邮件设置”中填写邮箱、SMTP 授权码、中继地址及密钥，点击“保存邮件设置”。这里只使用邮件字段，不需要视频作者 UID；修改也会影响视频邮件。
4. 勾选“将每日报告发送到邮箱”并保存。手动或定时生成成功后发送该报告及 Markdown 附件；不勾选则仅保存到本机。已有报告也可点击“发送到邮箱”。
5. 需要每日自动生成时，启用自动生成并选择时间，默认 23:50。凌晨 06:00 前总结前一天，其余时间总结当天；启动时会尝试补生成昨天缺失的报告或补发已有报告。浏览器需运行，休眠或关闭可能导致延后。

采集开关仅控制新页面摘录；即使不开启，也可以主动生成历史标题与网址的日报。开启自动生成即允许定时读取历史资料并请求所选模型。关闭“将正文摘录发送给所选模型”后只使用标题和网址；关闭新页面采集不会删除已有摘录，需要时可清空日报数据。

旧历史没有正文时，只标注“未采集正文”，不会自动回访全部历史链接或编造阅读内容。每天最多采集 500 个页面 URL，历史查询最多返回 3000 个 URL；每次默认最多纳入 100 条（可设 10–300），另有约 40000 字符输入预算。超出时抽样、缩短摘录或减少条数；日报显示记录数和实际纳入数，并为每一条纳入记录生成摘要。模型漏掉任何一条摘要时明确失败，保留上次成功报告。

相同资料与模型配置复用已生成结果；同一版本、同一收件人不会重复发送。资料更新后重新生成会形成更新版，勾选邮件时可发送更新版本。SMTP 结果未知或任务在发送中断开时暂停重发，需核对邮箱并明确确认可能重复后才重试。发信失败不会删除已经生成的日报，重试邮件不需要再次调用模型。

日报长任务在独立任务窗口中执行，避免后台服务休眠中断。请不要关闭正在生成/投递的任务窗口。日报正文、任务及邮件状态保留约 90 天；“清空浏览日报数据”只清理该模块，不修改 API、邮箱、视频队列或浏览器原始历史。任务执行中需等待完成后再清理。

升级会新增 history 权限，Edge 提示时需要允许此功能。不同扩展 ID 的本地存储不会自动合并：原独立浏览日志扩展的数据仍保留在原扩展中，整合版使用自己的日报存储，并读取当前 Edge 用户配置的浏览历史。

## 邮件中继

浏览器无法直接连接 SMTP；中继接收 HTTPS 邮件请求，再经 TLS 连接 SMTP 服务器。发件地址和 SMTP 凭据会经过你的 Worker，收件人会看到正常发件邮箱。预设中继仅支持 smtp.163.com，必须配置有效中继密钥；其他 SMTP 服务请自行部署 relay-worker.js 并调整 SMTP_HOST。支持 465 TLS 和 587 STARTTLS。

中继需设置 ACCESS_KEY（至少 24 个随机 ASCII 字符），扩展填写相同密钥。邮件 JSON 最大 30 MiB，外层邮件 base64 最大 28 MiB，完整 PNG 最大 8 MiB，超限会等比缩小整图或明确失败。邮箱自身还可能限制发送频率和附件大小。

## 视频与任务限制

B 站使用可用且时间覆盖合理的字幕；字幕不可用时改读评论区「文字版」链接（UP 主置顶评论常带文字稿链接）作为总结依据，报告注明总结基于文字版而非逐字字幕。字幕与文字版都拿不到时：视频发布 24 小时内保留待办等 AI 字幕生成，超期后改为仅凭视频文案/标题总结，并在报告与速评中明确说明「字幕与文字版均不可用」的情况。抖音无字幕时，用户勾选“此模型支持图片输入”后可分析文案和最多 5 张真实关键帧；未勾选时仅使用文字。请先核实所选模型支持 OpenAI 兼容的图片输入，报告注明未分析音频。没有音频转写功能。B 站多 P 当前仅涵盖第 1 P。

每轮最多成功发送 2 封、最多尝试 8 项；默认每 6 小时检查。浏览器需运行。任务使用独立窗口，请勿在任务中关闭、切换或缩放工作窗口。作者列表当前只读取已渲染作品，没有完整历史翻页。

视频优先导出允许读取的已解码帧，失败时检查遮挡并裁切窗口截图，不绕过跨域限制。报告使用净化 HTML，最大 30000 CSS 像素、约 2400 万像素画布，覆盖完整后才导出。邮件含预览图及普通 PNG 附件。

模型和发送任务运行于独立任务页，后台服务休眠不应中断任务。确定发信失败可复用已生成报告；投递结果不确定时暂停自动重发，需要核对收件箱后手动重试，可能产生重复邮件。

## 开发测试

无构建依赖。离线检查：

    node --test tests/regression.cjs keydock/tests/core.test.mjs keydock/tests/background.test.mjs keydock/tests/integration.test.mjs daylog/tests/engine.cjs daylog/tests/mail.cjs daylog/tests/background.test.mjs

隔离 Edge 模拟联调：设置 PLAYWRIGHT_MODULE、EDGE_EXECUTABLE（可选）、TEST_OUTPUT 后运行 node tests/browser.cjs。外部业务请求使用模拟响应，不使用真实模型额度或 SMTP。service-worker.mjs 是整合入口，keydock/options.html 为 API 管理页，pipeline.js 为采集、总结与发信流程。

日报隔离 Edge 联调：指定 TEST_OUTPUT 为发行目录外路径，再运行 node daylog/tests/browser.cjs。测试只使用虚构历史和模拟接口，不读取实际用户配置、不消耗模型额度、不发送真实邮件。不要用 node --test daylog/tests/*.cjs 通配符把浏览器脚本混入离线测试。
