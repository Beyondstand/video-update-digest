视频更新速递 · 浏览记录

日报设置

先选择采集范围，再决定何时生成、是否发送。

共用 API 配置

日报使用 KeyDock 当前选中的模型和本次会话 Key；重启浏览器后，手动录入的 Key 需要重新填写。模型资料和日报设置分别保存。

共用邮件设置（点击展开）

日报和视频使用同一套邮箱、中继配置；此处修改也会影响视频邮件。仅使用日报时无需填写视频作者 UID。先保存邮件设置，再开启下方邮件投递选项。

填写授权码，而非邮箱登录密码。该凭据会经 HTTPS 交给你配置的中继。

采集与资料范围

历史标题和 URL 可作为补充；插件不会自动重新打开全部历史网页。超过页数或约 4 万字符输入预算时，会均匀抽样、缩短摘录，报告只涵盖选入的记录。生成时清理约 90 天之前的浏览日报数据。

包含 * 时匹配完整 URL；不含 * 时按子串匹配。命中的站点不采集，也不进入日报总结。可在这里排除邮箱、网银等敏感页面。

生成与邮件投递

凌晨 06:00 前总结前一天，其余时间总结当天；当天稍后新增的访问不会出现在已生成报告中。

发信失败时，已经生成的日报会保留。若投递结果不确定，请先核对收件箱，再选择重试；重试可能产生重复邮件。
