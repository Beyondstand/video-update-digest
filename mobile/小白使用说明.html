知了 Reelize · 小白使用说明

视频更新自动总结速递——盯更新、出总结、送邮箱

一句话介绍：它会自动盯着 B 站作者的新视频，帮你把视频总结成一封邮件发到你邮箱——不用你看完视频。

第一步：安装

  1. 手机打开下载页（GitHub 的 Releases），下载 app-release-v1.0.apk。
  2. 点击安装。手机若提示「禁止安装未知应用」，点设置 → 允许来自此来源，再装一次。
  3. 装好后打开 App，图标是一个看书的小人。

第二步：登录 B 站（必做）

  1. 点「打开 bilibili 登录」按钮，在弹出的网页里扫码或账号登录。
  2. 登录完点「完成」。提示「登录态已保存」就成功了。
为什么要登录？App 需要读取你关注作者的视频列表。登录信息只保存在你自己的手机里。

第三步：填 3 组配置

填什么去哪里拿示例
B 站作者 UID电脑打开作者空间，网址里那串数字98639326
模型 API + 模型 ID + Key你用的 AI 服务商（如 OpenAI 兼容平台）的控制台https://api.example.com/v1
收件邮箱 / 发件邮箱 / SMTP 授权码邮箱设置里开启 SMTP，生成授权码（不是登录密码）163 邮箱 → smtp.163.com
SMTP 授权码不是邮箱密码！163/QQ 邮箱要在「设置 → POP3/SMTP」里单独开启并生成。

第四步：点「立即检查更新」

  1. 先点「保存配置」。
  2. 再点「立即检查更新」，下方日志会一行行显示进度。
  3. 看到「邮件已发送」就去邮箱查收吧！

可选功能

  • 生成图文讲解页：「运行」卡片里的开关。开启后每封邮件多附一份 lecture.html 图文讲解（手机/电脑浏览器直接打开看）。开关自动保存。
  • 加密保存：点「设置保管密码」，模型 Key 和邮箱授权码会加密存在手机里；重启 App 点「解锁恢复 Key」就不用重填。

常见问题

问题解决办法
提示「接口返回异常」多半是没登录 B 站，重做第二步
提示「模型 API 返回 HTTP 401」Key 填错了，重新复制完整 Key
提示「SMTP 认证失败」用的是邮箱登录密码？改用 SMTP 授权码
日志说「无新视频」正常！说明该作者还没发新视频
邮件说「字幕与文字版均不可用」正常，该视频没字幕；总结基于视频简介，细节可能不全
